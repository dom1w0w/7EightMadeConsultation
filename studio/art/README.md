# Studio art

Images for the Art section of https://dom1w0w.github.io/7EightMadeConsultation/studio/#art

1. Put each image in this folder (web-sized, about 1600px on the long side, JPG or WebP).
2. Add one entry per piece to `art.json`, newest first:

```json
[
  { "title": "Piece title", "year": "2026", "medium": "Acrylic on canvas", "image": "piece-title.webp", "alt": "Short description of the image" }
]
```

`title` and `image` are required. `year`, `medium` and `alt` are optional.
Only touch files in this folder.
